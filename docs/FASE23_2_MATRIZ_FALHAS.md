# Fase 23.2 — matriz de falhas financeiras

Todos os dados são sintéticos. `201 → rede interrompida → 200` descreve o HTTP produzido pelo backend e o que o navegador observou; o cliente não recebeu o primeiro `201`. `0/1` em SQL são contagens verificadas depois da operação. Chamada de provedor significa chamada ao adaptador simulado; nunca ao provedor real.

Os testes de dois servidores aguardam a segunda instância sinalizar `ready` antes de soltar as duas requisições. A ordem exata de chegada ao lock pode variar; cada teste verifica o resultado financeiro por SQL e conta as chamadas do adaptador compartilhado. O teste de hold de poltrona separado usa barreira IPC para a aquisição.
